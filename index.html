Getting Started

  1. Install n8n: docker run -p 5678:5678 n8nio/n8n or sign up for n8n Cloud
  2. Import a workflow: Click "+ New" → menu (three dots) → "Import from file" → select a JSON file
  3. Set up credentials: Add an OpenAI API key in n8n settings, configure any service-specific credentials shown in the workflow
  4. Activate: Click "Activate" to start the workflow running on its schedule

What n8n Is

n8n is an open-source workflow automation tool. Unlike Zapier or Make, n8n can be self-hosted for free, giving you full control over your data and workflows. Thousands of nodes connect to virtually any service.

The 5 free workflows above demonstrate core n8n patterns: scheduling, API calls, AI processing, and delivery. Each one is a building block for more complex automations.
