1. Setting Up n8n

Choose your deployment pathSelf-hosted (free, full control) or n8n Cloud (~$24/mo, managed). Self-hosted is the default for most users who want to maximize value.
Spin up n8n with Dockerdocker run -it --rm --name n8n -p 5678:5678 -v ~/.n8n:/home/node/.n8n n8nio/n8n
Visit http://localhost:5678Create your admin account. You'll land on the workflow editor.
Install the OpenAI nodeSearch for OpenAI in the node palette. Connect your API key. This unlocks AI classification, text extraction, and summarization.
Connect your first appGmail, Slack, Telegram, Google Sheets, Stripe -- whichever is most valuable to your workflow. Use OAuth where available.
Set up credentials and test each connectionEvery workflow starts and ends with connections. Get them working before building anything complex.

2. Building Your First Workflow

Start with a trigger nodeSchedule (Cron), Webhook, Gmail (new email), or a manual button. Pick the one that matches your automation goal.
Add a Set node to define the structureEven simple workflows benefit from explicitly shaping the data before it flows through. Define what your output should look like.
Build the transformation chainHTTP Request, Code, Split In Batches, If -- these are the building blocks of every workflow. Chain them in the order that makes sense for your data.
Add an output actionSend a Slack message, write to Google Sheets, post to Telegram, or create a Stripe charge. Your workflow is only useful if something happens at the end.
Test every step before activatingUse the Execute Node button to run each node individually. Check the output before moving to the next node.
Activate and monitor for one dayLet it run. Watch the execution log. See what actually works and what needs adjustment.

3. Core Automation Patterns

These patterns cover most of what people use n8n for. If you master these, you can build most workflows:

Pattern A: Inbox Intelligence

Gmail trigger to AI classification to message sentScan emails, classify with OpenAI, send digest to Slack/Telegram. This is the single most popular n8n workflow people build.

Pattern B: Document Processing

Email attachment to OpenAI extraction to database/SheetInvoices, receipts, contracts -- use AI to pull structured data from unstructured documents.

Pattern C: Content Repurposing

YouTube/RSS to OpenAI summarization to social postsTurn one piece of content into multiple formats across platforms automatically.

Pattern D: Lead Capture and Routing

Webhook/form to data enrichment to CRM/Sheet/Slack alertCapture leads from any source, enrich them, and route to your pipeline instantly.

Pattern E: Monitoring and Alerting

Schedule check to HTTP request to If branch to Slack alertMonitor any API, webpage, or system and get notified when something changes or breaks.

4. Error Handling and Reliability

This is what separates a workflow that works in testing from one that works in production:

Add error handling branchesEvery workflow should have an error path. If the main action fails, notify yourself via Slack or email instead of silently failing.
Use the Error Trigger nodeSet up a global error handler that runs when any workflow fails. It can send alerts, log to a file, or retry.
Add retry logic with Wait nodesWhen calling APIs, sometimes they fail temporarily. Use Wait nodes with exponential backoff instead of immediately erroring.
Validate inputs before processingUse If nodes to check that required data is present before sending it to OpenAI or an external API.
Log outputs for debuggingAdd a node at the end that saves the full workflow output to Google Sheets or a file.

5. Production Deployment

Move n8n from --rm to a persistent Docker setupUse docker-compose with environment variables, persistent volumes, and automatic restart.
Set up a reverse proxy with HTTPSLet's Encrypt via Docker Compose or Cloudflare. Your webhooks need HTTPS to work with most services.
Store secrets in environment variablesNever hardcode API keys in workflow JSON. Use n8n's environment variable system.
Export and version-control your workflowsSave workflow JSON files in git. This is your backup and makes it easy to share templates.
Set up monitoring for uptimeUse a service like UptimeRobot or a simple n8n cron job that pings your instance every 5 minutes.
